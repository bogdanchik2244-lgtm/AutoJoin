Политика конфиденциальности AutoJoin

Дата последнего обновления: 14 сентября 2026 года

1. Общая информация

AutoJoin — настольное приложение, созданное для упрощения и ускорения доступа студентов к онлайн-занятиям.

Приложение использует Google Classroom API для получения информации из Google Classroom после того, как пользователь самостоятельно предоставляет необходимые разрешения через систему авторизации Google.

2. Какие данные получает приложение

В зависимости от предоставленных пользователем разрешений AutoJoin может получать следующую информацию:

  • список доступных пользователю курсов;
  • названия курсов;
  • разделы курсов;
  • задания и публикации в курсах;
  • текст заданий и публикаций;
  • информацию, необходимую для поиска ссылок на онлайн-занятия.

3. Как используются данные

Полученная информация используется исключительно для работы функций AutoJoin.

В частности, программа использует её для:

  • определения нужного учебного курса;
  • поиска актуальных заданий и публикаций;
  • поиска ссылок на онлайн-занятия;
  • отображения необходимой информации пользователю;
  • быстрого открытия найденной ссылки на занятие.

AutoJoin не использует полученную информацию для рекламы или продажи данных.

4. Хранение данных

Данные авторизации Google хранятся локально на компьютере пользователя.

AutoJoin не передаёт данные авторизации разработчику и не хранит их на собственном сервере.

Приложение не использует собственный удалённый сервер для хранения данных Google Classroom.

5. Передача данных третьим лицам

AutoJoin не продаёт и не передаёт полученные данные третьим лицам.

Для работы приложения используются сторонние сервисы Google Classroom API, Google Meet и Zoom. При переходе по найденной ссылке пользователь взаимодействует непосредственно с соответствующим сервисом.

6. Авторизация Google

Авторизация выполняется через официальную систему авторизации Google.

AutoJoin не получает и не запрашивает пароль от аккаунта Google пользователя.

Пользователь самостоятельно выбирает аккаунт Google и предоставляет приложению необходимые разрешения.

7. Отзыв доступа

Пользователь может в любое время прекратить использование AutoJoin и отозвать предоставленный приложению доступ к своему аккаунту Google через настройки своего аккаунта Google.

Пользователь также может удалить локально сохранённые данные авторизации AutoJoin со своего компьютера.

8. Безопасность

AutoJoin использует локальное хранение данных авторизации и не передаёт их разработчику.

Пользователь самостоятельно отвечает за безопасность своего компьютера и своей учётной записи Google.

9. Изменения политики конфиденциальности

Эта политика конфиденциальности может обновляться при изменении функциональности AutoJoin или способов обработки данных.

При внесении изменений новая версия политики будет опубликована на этой странице.
