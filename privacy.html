Политика конфиденциальности

AutoJoin — это настольное приложение, предназначенное для упрощения доступа студентов к информации из Google Classroom.

Какие данные использует AutoJoin

После авторизации пользователя AutoJoin получает доступ только к той информации Google Classroom, на которую пользователь предоставил разрешение.

Для чего используются данные

Полученная информация используется для отображения учебных курсов, заданий, объявлений и ссылок на онлайн-занятия.

Хранение данных

Данные авторизации хранятся локально на компьютере пользователя. AutoJoin не передаёт данные авторизации разработчику и не хранит их на собственном сервере.

Сторонние сервисы

AutoJoin использует Google Classroom API для получения информации из Google Classroom.

Удаление данных

Пользователь может удалить локально сохранённые данные авторизации с компьютера, удалив данные приложения AutoJoin.

Контакты

По вопросам, связанным с AutoJoin, можно обратиться по адресу электронной почты, указанному в настройках приложения Google Cloud.
